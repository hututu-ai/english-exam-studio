## 1.0.120：这次更新了什么？

这一版把使用说明重新整理得更简单，课件功能沿用 1.0.119。最近重点完善了下面几件事：

- **先问你要什么，再开始做。** 做整卷、只做听力精听，还是只做阅读？批注、查词、速对答案、课堂工具、篇章精读、写作迁移、文化背景，也由你按需选择。
- **少做重复工作，更省时间和积分。** 没选的板块不生成，能复用的听力处理结果尽量复用，减少来回返工。实际用时仍取决于材料、电脑和所用 Agent。
- **完善听力分段。** 先检查电脑上的语音工具；缺少时，在你同意后协助准备 WhisperX，先试一小段，再处理正式录音。整段听和逐题复听都要核对对应内容。
- **讲解更重视依据。** 文化背景要查来源、结合本篇；词义和篇章结构要对照原文；精听挖空要对应答案线索或明确的语音难点，不随便挖几个词凑数。
- **继续加强 Windows 适配。** 1.0.119 已通过 Windows、Mac、Linux 的脚本测试和示例浏览器检查。不同电脑和 Agent 的实际环境仍可能有差异，遇到问题欢迎反馈。

**已经装过的老师，让 Agent 更新一次即可。** 旧课件仍能打开；想让旧课件用上新功能，需要把它和原材料一起交给 Agent 重新生成。

## 怎么安装或更新？

打开你使用的 Agent，把下面整段发给它：

```text
请帮我安装或更新英语实战讲评 Skill：
https://github.com/hututu-ai/english-exam-studio

如果已经安装过，请先备份旧版和我的个性化修改，再更新。
请安装完整的 Skill，完成后运行 scripts/check_install.py，确认结果为 complete，告诉我安装好的版本。
先不用下载听力模型，等我提供材料、选好需要的板块后，再准备本次必需的工具。
```

这里的 **Agent**，可以理解为能帮你读取文件、安装技能和生成文件的 AI 助手。只有聊天功能、不能处理文件或运行工具的模式，无法完成整套课件制作。

**WorkBuddy、豆包办公怎么用？** 在支持文件处理和工具执行的任务中发送上面的指令，再上传自己的材料即可。不同版本的功能入口可能不同；如果助手提示当前环境不支持安装或运行，请把具体提示发来，不要只让它输出一段网页代码。

如果链接下载不成功，可以[下载完整 ZIP](https://github.com/hututu-ai/english-exam-studio/releases/latest/download/english-exam-studio.zip)，作为附件发给 Agent，请它解压安装；平台有“上传技能”入口时，也可以在那里导入。

更多安装问题见 [常见问题](docs/FAQ.md) 和 [更新说明](docs/UPDATE.md)。

## 怎么生成自己的课件？

### 1. 把材料放进同一个任务

| 材料 | 可以提供什么 |
| --- | --- |
| 试卷 | PDF、清晰完整的照片，页面按顺序提供 |
| 答案 | 对应的 Word、PDF、图片或文字；有解析、听力原文也一起给 |
| 听力 | 完整原始录音，例如 MP3，不用老师提前切割 |

只做阅读等文字板块时，不需要提供听力。答案文件里已经有听力原文，告诉 Agent 一起读取即可。

### 2. 发出生成指令，再选择需要的内容

```text
请用英语实战讲评 Skill 处理我提供的这些材料。
先让我选择这次要做哪些板块，以及需要哪些功能，再按我的选择生成教师讲评课件。
沿用 Skill 自带的界面和功能，核对原文、答案与听力，实际打开课件检查后，给我完整的课件压缩包。
```

助手会问你两件事：

- **这次做哪些板块？** 整卷、独立听力精听，或指定板块。
- **需要哪些功能？** 批注、查词、速对答案、课堂工具、篇章精读、写作迁移、文化背景，可以多选。

直接用平时说话的方式回答就行，例如：

> 这次只做听力精听，保留查词和批注，其他先不要。
>
> 这次做阅读和完形，需要篇章精读、写作迁移、文化背景。

### 3. 打开课件，准备上课

下载并解压完整课件包，用电脑浏览器打开 **index.html**。HTML 就是一个用浏览器打开的课件，不需要老师写代码。

上课前先看看重点题的解析，听一下准备播放的片段。换电脑时带走整个课件文件夹；课堂修改和批注记得另外导出“课堂记录”，到新电脑后再导入。

## 课上可以怎么用？

| 想做什么 | 可以这样用 |
| --- | --- |
| 讲听力 | 先看题再听音，整段播放或逐题复听，调整速度，逐空揭示关键表达 |
| 讲阅读、完形等 | 原文和题目左右对照，解析一道一道打开，定位答案依据，译文逐段展开 |
| 快速核对答案 | 看整卷答案，或按听力、阅读、七选五等板块查看 |
| 讲词句、读写迁移 | 查生词、讲熟词生义和重点句式，找出适合写作的表达 |
| 补充文化背景 | 从本篇内容出发，了解相关背景，再回到文章理解 |
| 边讲边标记 | 红笔、箭头、矩形、圆圈；记录易错点、标记待复讲题目 |
| 调整展示 | 顶部切换板块，调整字号、单栏或双栏，选择青绿、紫曜等浅色主题 |

功能是否出现，以你本次的选择和提供的材料为准。

## 能按我的上课习惯修改吗？

可以。课件中的 **备课编辑** 可以修改支持编辑的讲解和词句，课堂记录可以导出保存。需要更大的调整，直接告诉 Agent：

> 我习惯先通读文章，再逐题讲。译文一段一段开，完形的写作迁移多讲一点。

满意后，再让它把适合反复使用的要求保存进你自己的 Skill。下一次换试卷，还可以继续调整。

## 老师常问的几个问题

**需要额外申请 AI API 吗？**  
基础流程不要求你再申请一套 AI API，使用的是当前 Agent 的能力。Skill 免费；Agent 的积分或费用按平台规则计算。

**生成后可以离线上课吗？**  
已经打包好的原文、解析和本地听力等基础功能可以离线使用。在线查词需要网络，系统朗读取决于电脑上是否有相应语音包。

**为什么第一次处理听力可能慢一些？**  
可能需要准备工具和下载模型。以后环境和同源处理结果能复用时，就不必每次从头准备。

**会不会生成和视频里完全不同的页面？**  
Skill 使用固定课件模板，按你选的功能填入这张卷子的内容。平台必须能运行配套工具；如果环境不支持，Agent 应说明原因，不能给一个简化网页冒充成品。

**能保证所有电脑、所有讲解都没有问题吗？**  
不能。我们持续检查和改进，但每张卷子的文字、答案与听力仍需要核对。WorkBuddy、豆包等不同环境的整卷生成，也需要继续积累实际使用反馈。

**包含学生学案或整本五三教辅吗？**  
默认交付教师讲评课件，不生成学生学案，也不附带商业教辅。你可以提供自己有权使用的参考资料，让 Agent 结合本卷整理。

# 用户教研资料与词典

新任务只使用当前用户实际提供、可读取且有权用于该任务的试卷、答案、听力、教材和教辅。先盘点资料类型及位置，不假定存在创建者的外置硬盘、五三文件夹或其他本机资料。

扫描教辅按考点查目录，读取相关页并核对页脚；PDF页序与印刷页码分别记录。仅看过部分页就只说核对了相应考点，不称整本已经OCR或入库。新卷先按具体考点取用材料，再独立组织规则、例句与本题联系。

把所需知识写成题目里的 knowledge 卡，出处可记录在 reference 或教师核对资料中；课堂上直接呈现知识，不给老师或学生布置跳转某书某页的任务。未提供教辅时仍按原卷与通用英语知识编写，不编造书中页码或来源。

公开 Skill 不打包教材、真实试卷、原始考试录音或私人课堂记录。成品引用和资产只来自本次材料，最终资源复制到成品目录，不依赖外部个人文件路径。

## 默认词库

公开包内置 ECDICT 的 10,836 条基础释义（MIT，许可随包），不附带创建者旧课件的私人词库。模板支持可选 legacy_dictionary；只有当前用户提供并明确可使用的资料，才按任务需要整理进自己的成品。

生词、重点词汇和句子精讲按本篇原文另行编写。基础词库标签不代表高考词频，也不保证每个查询都有准确的本篇语境义。

Wiktionary REST 默认提供在线英文补充，Free Dictionary API 为备用，见 [在线词典](online-dictionaries.md)。Oxford Learner’s Dictionaries 只作为人工详查外链；不把商业词典或教辅整库抓取进公开包。

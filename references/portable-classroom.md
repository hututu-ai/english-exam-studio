# 单文件课件、手动挖空与触屏验收

新生成默认使用 embedded 音频模式。用户希望转发一个 HTML 时不可改用 folder 模式；同一 HTML 内包括完整录音、题组录音、逐题录音以及原卷图片。不要把模板自带的“导出单文件课件”删除。听力切片的真实性仍须执行原有对齐、试听复核流程。

## 老师怎么修改挖空

展开“原文与精听” → “修改挖空” → 在原文框中选中词或短语 → “设为挖空”。点已有词语的 × 可以移除，支持恢复生成时挖空。原文框只读，不允许以改写原文来造空。保存后标记为教师手动选择，与 Agent 的教学复核结论区分。刷新保留修改，课堂记录导入导出也包含修改。

“导出单文件课件”将内嵌音频与教师挖空配置放入新的 HTML；转发这个新文件，对方无需 audio 文件夹。此按钮当前保存挖空设置和课件内容，批注、积分等完整课堂过程记录仍使用“导出课堂记录”。不要宣称会把所有未保存的课堂状态自动带走。

## 手机、iPad 与白板

- 播放必须由老师点击触发；不承诺有声自动播放。使用系统浏览器打开完整 HTML。微信、文件 App 快速预览或宿主内嵌预览可能禁用脚本、下载或声音；这不等于浏览器打开。iOS 没有可用的本地 HTML 浏览器打开路径时，可将同一单文件放到老师认可的静态网站，再用 Safari 打开链接，不声称任意文件预览都可离线播放。
- MP3 是建议音频格式。构建在内嵌模式下会将 OGG/Opus 等其他后缀转换为 MP3，需要 FFmpeg；已有 MP3/WAV/M4A/AAC 保留，最终仍需实际播放验收，不以扩展名代替播放结果。
- “白板模式”放大操作目标和字号，章节菜单可点开，不依赖悬停；红笔等沿用页面批注。希沃设备优先使用 Windows 的 Edge/Chrome 打开 HTML 后全屏。这是网页触屏适配，不是转换成希沃原生课件。希沃内置浏览器版本不同，须实测，不保证旧内核。
- WebKit 的有声播放手势要求：https://webkit.org/blog/6784/new-video-policies-for-ios/
- 希沃官方帮助：https://help.seewo.com/easinote/ZSCpIoCGY7

## 验收

1. 生成内嵌音频示例，把 index.html 单独复制到无 audio/sources 文件夹的目录；断网打开，实际播放整段、逐题，调速和切换章节。
2. 修改词语/短语、移除、恢复、保存刷新、导出后新浏览器上下文打开，核对每空逐字来自原文；重叠范围和越界记录应被拒绝。
3. 检查 390px 手机、820px 平板与 1920px 白板；按钮触屏点击、正文不横向溢出、弹窗可滚动、播放失败有可见提示。
4. 自动浏览器手机仿真不能写成 iPhone/iPad 真机通过；Mac 浏览器测试不能写成 Windows 希沃实机通过。报告分别列出执行的引擎、尺寸与未实测设备。

# 无 Whisper 时如何完成听力

1.0.119 默认处理入口为 [统一 WhisperX 链路](whisperx-workflow.md)。先记录老师本次范围与功能。下文 whisper.cpp 命令仅供已存在的备选环境使用，不因缺少它而安装另一套；不经老师同意降级。


Whisper 是可选转写后端，不是课件播放器的依赖。Windows 与 macOS 使用同一 Python 流程；不要求 Windows 老师运行 `.sh`、brew、sudo 或照抄容器 `/root/...` 路径。

## 缺工具先协助安装，不直接降级

选了听力且没有现成可用转写/同源字幕时，先读 [Whisper 准备](whisper-setup.md)。说明下载内容、位置与预计体积，在用户授权范围内协助准备并试转短录音；成功后继续完成逐题精听。不因缺 Whisper 就立即交付基础原音版。

## 按材料选路径

1. **有同一录音的带时间字幕 SRT / VTT / JSON**：用 `scripts/import_timed_text.py AUDIO SUBTITLES --out WORK_AUDIO/transcript.json --same-recording-confirmed` 统一格式，复用其时间轴。该命令不启动 Whisper；仅校验格式、实际音频时长和指纹，不代表字幕内容已经回听。接着用题意及实际回听生成题组、逐题清单，直接 `audio.py cut`，不必重跑 analyze。录音剪过头尾、加过片头或变过速就不是相同时间轴。
2. **有答案册听力原文，但没有时间轴**：原文用于教学文本，无需重新识别这些字。Agent 若能听音频，可结合首尾回听、题号提示和静音候选制作清单，再用 FFmpeg 裁剪。若已有支持“音频+给定文本”的强制对齐工具，也可复用；对齐只匹配给定文本，不证明原文完整，更不能凭空识别省略或重复朗读。必须核对实际首尾。不要默认要求老师下载新模型。
3. **只有音频**：优先使用宿主已经提供的音频理解或转写工具，只使用真实返回的内容/时间戳；也可使用已可用的其他 ASR 后端，再规范成 segments JSON。不得把网页语音合成当原卷录音。外部收费 API 或上传录音需单独说明并获得相应授权，不要求每个老师填 API key。
4. **完全不能转写、听音或对齐**：音频仍内嵌，交付“整段原音可播放，逐题切点待核对”；有可信原文才提供原文挖空。用户选了精听时，明确询问接受基础版，还是补充原文/同源字幕后完成。不能将这种降级标为“完整精听已完成”。其他选中板块继续，不替用户切换成整卷。

本地 FFmpeg 能裁剪不代表必须安装 Whisper。带时间 JSON 直接用于 cut；静音检测只能提供候选，不能等分 10 段、按题数平分或按文本字数推算切点。Agent 完成清单，不把 JSON 和手工剪音任务转给老师。

现有工具可参考官方说明：aeneas 支持给定音频与文字同步（https://www.readbeyond.it/aeneas/）；WhisperX 支持转写及词级对齐（https://github.com/m-bain/whisperX）。它们各自仍有模型/环境依赖，本 Skill 不声称已内置、无需安装或所有电脑开箱即用。默认先走可用依赖路径，120 秒下载预算后说明受限项。

## 验收分层

记录格式/时长 → 同源指纹 → 实际听到的内容和首尾 → 题目完整语境 → 浏览器播放。任何一层未检查，写明待核；纸面原文不自动获得录音秒数。通常精听空位围绕转折、否定、数量、行动与原因、同义替换，保留完整短语。复用上一版原音指纹与切点完全匹配的切片，避免反复转写。

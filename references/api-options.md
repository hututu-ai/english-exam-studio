# API 应该加在哪里

建议把需要模型或密钥的 API 放在“生成课件”的环节。老师仍只提供试卷、答案和音频；生成完成后，课堂播放、逐题讲解、双语、核心词库和练习可离线使用。额外在线释义与词典录音需联网，系统朗读是否离线可用取决于设备声库。

目前这套 Skill 已能由智能体组织本地识别、转写、内容编写、切段、校验和课件构建。它不是一个需要另填付费密钥才能上课的网站；这次也没有新增付费云端调用。

| 优先级 | 可增强的能力 | 对老师的实际价值 | 当前已有路径 |
|---|---|---|---|
| 高 | 扫描试卷识别与版面理解 | 减少选项黏连、图表遗漏、下划线丢失，适合扫描件质量不稳定的情况 | 本地提取/OCR，智能体对照原页校核 |
| 高 | 音频转写、词级时间与对齐 | 更稳地自动生成Text和逐题音频，并核对精听空位 | 本地Whisper及真实时间对齐，切段后独立转写检查 |
| 中高 | 按固定结构生成解析，再独立核对 | 稳定覆盖题型、证据、干扰项、方法、词句与写作迁移，减少漏项 | 当前智能体按照Skill规范编写，构建器检查结构与引文 |
| 已有的可选联网能力 | 在线词典 | 补充离线库之外的英文释义、例句及有收录时的音标/录音 | Wiktionary与Free Dictionary API无密钥双源；失败切换并保留离线结果，现场可用性另测 |
| 可选的生成阶段增强 | 本句语境义与词汇迁移 | 根据原句选合适义项，整理搭配、易混点与写作例句，再固化到课件 | 当前依本卷已编写教学词条；尚未新增实时AI查词或额外付费调用 |
| 后续扩展 | 临时变式题、学生作文反馈 | 教师上课时按学生情况追加练习或反馈 | 尚未做成在线功能，不影响当前成品使用 |

具备视觉能力的模型可同时读取PDF提取文本与页面图像，适合辅助检查版式；这仍需与原题、答案核对。[文件输入官方说明](https://developers.openai.com/api/docs/guides/file-inputs)

语音转写和精准定位是两层能力。选择接口前要确认模型是否返回所需的词级时间，不能把只有文字的转写当作对齐结果。当前官方文档中，`timestamp_granularities[]`只适用于`whisper-1`；其他服务也要逐项确认时间信息，必要时加本地强制对齐。[语音转写官方说明](https://developers.openai.com/api/docs/guides/speech-to-text)

结构化输出能约束字段格式，但不能保证答案或教学分析正确。需要独立检查题号覆盖、答案来源、引文原文、逻辑与音频边界。[结构化输出官方说明](https://developers.openai.com/api/docs/guides/structured-outputs)

## 我的建议

先把现在的“资料输入→整卷课件＋学生学案”做稳定，按实际遇到的识别问题选择性接入API。最值得优先增强的是扫描识别和听力对齐；主题切换、逐题显答、音频播放、精听挖空、课堂工具不需要API。

如果以后要做成任何老师都能使用的上传网站，再增加服务端文件管理、任务进度、模型适配和失败续跑。密钥仅存本机环境或服务端，不能放进HTML、浏览器存储或发给老师的压缩包。

## 词典和高考资料是否还要增加

当前先保留现有离线词库、开放在线释义、旧词库和已经核对的五三考点。关键是把语境义、搭配辨析、解题方法和写作迁移讲准确；继续堆整本资料不会自动提高课件质量。后续如确有不足，优先增加可核实来源的真题例句和同考点变式，记录年份、题号与授权范围，避免把商业词典或教辅整库打包分发。

五三相关知识已整理为本题知识卡；页码只留在数据来源中，不让学生跳到教辅查页。


## 词典增强的技术选择

当前使用“离线词库＋本篇已编写语境义＋在线补充＋系统朗读”，已有词典 API。优先修好词形还原、原句关联、释义层次和录音来源，通常比增加更多词典入口更有课堂价值；六种浅色皮肤不改变这套交互。

推荐下一步在生成阶段，将目标词、必要原句上下文、检索得到的义项和教学目标交给模型，产出语境义、依据、关键搭配及一个迁移例句。独立核对后随课件离线保存；未核对的模型解释不能标成词典原文。此方案为可选扩展，当前公共词典查询仍只发送词语，不会因此上传整篇试卷。

如需更多结构化开放数据，可评估 Wiktextract 提取的义项、词形、发音和翻译，在生成阶段按卷筛选并保留各自许可。它是数据提取路线，不是已经接入的托管在线服务。[官方字段文档](https://github.com/tatuylonen/wiktextract/blob/master/README.md)

商业词典适合有明确预算与授权范围后的升级。Cambridge 提供 API 与数据授权咨询；Oxford Dictionaries API 需要账号凭据，提供包括词条和英美录音在内的数据，但官方 FAQ 明确缓存及离线保存只在 Enterprise 许可下允许。普通查询套餐不能默认用于打包离线词库；本项目未购买或接入这些商业服务。[Cambridge 开发与许可入口](https://dictionary.cambridge.org/develop) · [Oxford 认证方式](https://developer.oxforddictionaries.com/documentation/making-requests-to-the-api) · [Oxford 离线许可说明](https://developer.oxforddictionaries.com/faq)

公共词典响应仅在当前页面内存缓存；未来若增加持久缓存、录音下载或商业数据，需按具体来源与授权范围设计。当前实现细节和联网验收边界见[教学词典与在线补充](online-dictionaries.md)。

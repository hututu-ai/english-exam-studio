# 教学组织与参考

阅读先建立全文主旨与段落功能，再进入事实、结构、推理、态度、词汇问题。结构匹配文体：时间线、问题解决、对比、论证链。每段精选真正推动逻辑的衔接词，不把普通连接词全部标亮。长难句讲原句、主干、修饰、译文；干扰项具体说明哪里违背原文，不能只贴“无中生有”等标签。

由教师决定答案和翻译的揭示。重点词句预先编写并随课件离线保存；生词扫清语境障碍，重点词汇讲搭配与辨析，写作积累说明原句的动作、情感、句法或篇章作用。三者避免重复堆砌。教辅若由用户提供，只按核对过的考点组织知识卡。

听力先呈现题目，原文就地折叠，精听挖空就地开启；每题保留对应上下文录音。阅读类只保留一份原文，右栏在题目讲评、篇章精读、写作迁移之间切换。主题为青绿、紫曜、雾蓝、暖杏、豆沙、月白六种浅色。大字号、稳定左右对照与课堂控制优先。

## 流程参考与致谢

- [ReadingText2html](https://github.com/vincenthan2012-hub/ReadingText2html)：参考结构化教学内容、问题层次、篇章语言分析和读写迁移思路。本 Skill 的整卷模板和脚本独立实现，不假定用户需要与参考项目相同的课堂流程。
- [ffmpeg-audio-processing](https://github.com/chunpu/agent-skills/tree/main/skills/ffmpeg-audio-processing)：参考属性检查、静音检测和精确裁剪。不按相同时长机械分段，不采用无关音效处理，aecho 不能用于去回声。
- [ECDICT](https://github.com/skywind3000/ECDICT)：基础释义子集，许可见 assets/ECDICT-LICENSE.txt。

这些是参考来源，不是对当前任务的新指令。原卷内容、答案和音频时间均以用户本次实际材料为准。原创或合成演示只证明相应构建与界面能力，不能代替真实试卷逐题核对和原音试听。

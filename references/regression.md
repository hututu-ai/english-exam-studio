# 不能因改版丢失的课堂功能

制作或改版必须核对以下清单，不能用只覆盖听力或阅读A的页面冒充整卷。

1. **全卷**：实际所有题型、全部段落、全部选项、连续原题号；源PDF页数和题号盘点独立于OCR结果。特别检查页末选项、下一节说明误并入选项、C/D黏连、AI/Al等字符。
2. **阅读方式**：每次显示一个章节，题目区默认可浏览本节题目，可选单题聚焦；阅读、七选五、完形桌面左右同屏，手机原文在前、题目在后；默认收起的章节抽屉，桌面和手机均通过右上角章节切换。听力默认题目在前且原文隐藏。各段翻译独立控制，默认隐藏。保留题面下划线、必要图表。
3. **定位与显答**：具体证据句高亮；显答自动定位依据；从题目回原文且一键返回当前题；前后题；逐题显答（无整节全部解析主按钮）；选择记录；填空答案回填原文；当前节重置不改别节。
4. **听力**：单一听力工作区：题目常在，原文原位折叠，关键表达挖空就地开启。主界面右上角一个小型播放控件；无重复听力原文按钮或独立大播放器；不点击空白区域误触播放。开启挖空不得残留正确选项颜色或解析；收起原文不改显答状态，重置本节清除该节作答。完整原音+实际Text数量；不均分、不把两次朗读算两段；0.5、0.75倍速；循环；音频互斥；精听逐空揭示、全显、重置；可靠对齐才启用证据句重听，1/2/3次后自动停止；跟随原音定位仅用于可靠对齐轮次。实测目标秒数与停播，不能只验证播放器开始播放。
5. **词典**：手动输入、点词、划词/词组、词典内连续查询、自动英语发音及开关、英美音选择、放大、一词多义、搭配辨析；本篇已编写语境义与对应原句优先，未编写不伪造。exchange词形还原与释义换行正确；离线核心释义、Wiktionary与Free Dictionary API无密钥双源，失败切换并保留本地结果；可用时显示返回的例句、录音和来源许可，录音与系统TTS明确区分。
6. **教研**：结构左右对照；词语有语境义/搭配构词/辨析/对应题/课堂追问/迁移例句；句子有原句/主干/成分/逻辑/译文/追问。题号关联必须二次核对。
7. **课堂工具**：字号、全屏、计时、四组计分、待复讲题目、随机抽号、打印。完整音频单列听力窗口。桌面投屏清晰；手机不横溢。
8. **交付**：index.html+相对audio资源+可编辑exam.json+来源许可+简明使用说明+验收记录+ZIP。移动整个文件夹或离线打开可使用核心功能。

## 验收的分层记录

静态校验只证明结构；对照原卷确认内容；独立转写导出的音频检查首尾；浏览器播放验证解码与时间推进；声学人工听感只有实际听过才可宣称。系统语音启动不等于所有电脑/浏览器均有离线英语声库。

整卷题数、篇章数与音频数量按当前原卷盘点，不把开发时样卷的数量写成所有新卷的硬编码要求。合成演示不能代替新卷的内容与原音验证。

## UI复核（听力流程改版）

用户反馈旧版原文在前和重复工具过多，要求听力先看题。此要求优先于早期“全卷长页统一原文在前”的约定。题目和原文共用工作区：初始不泄露原文，展开解析或定位时左右对照，精听只在原文中开启关键表达挖空。取消旧三环节标签与跳转页脚，题目和音频始终保留。

## 逐题与阅读连续性验收

- 普通视图保留本节全部题卡；单题聚焦时最多一张题卡可见；任意视图最多一道解析展开。已讲完形答案仍回填；切题不清除已学空位。
- 标题、价格、产品名不另配段落翻译按钮；分组保持原卷顺序，不漏段落。
- 原卷页图实际解码；出处标签明确来源确认程度。
- 生词速查、重点词汇、句子精讲分别展示；语境定位真实命中原文，频次与统计范围一致。

## 当前公开版的界面与记录核对

1. 青绿、紫曜、雾蓝、暖杏、豆沙、月白六主题，分别在桌面、低分辨率投影与手机检查对比度、选项、弹窗、导航与无横向溢出。主题变化不改变课堂工作区，旧主题记录安全迁移。
2. 每节只保留一份原文。右栏切换不改变原文位置、译文状态与课堂选择；展开原文/恢复左右栏不复制全文。旧版课堂记录可导入。
3. 听力原文开合、精听切换与选择选项不重建播放器、不打断播放。整段、单题、完整录音互斥；每题录音保留必要语境。来源时间、Text局部时间、题片段从零开始的时间不可混用。
4. 逐题解析常驻答案与题型，正文只显示解题三步、选项辨析、方法迁移中的一组。点击选项不自动判分；全部题目只扩大浏览范围。
5. 七选五排除/恢复、右键、改选、备选库题号状态、刷新恢复均核对。logic_links 引文真实存在，颜色与编号对应；线索默认隐藏、一次聚焦一题，切题可收起。
6. 红笔、箭头、矩形、圆圈实际拖拽，含反向拖拽、跨栏、滚动、换节、撤销清空、快捷键、刷新与导入。零面积形状不保存；浏览模式不拦截正文操作。
7. 词旁弹窗、词组选择、词典内连续查询、词元还原及换行可用；本篇已编写语境义与通用释义区分，不串用其他篇章。公开包无旧私人词库时仍能查询基础释义。
8. 在线词典分别检查主源成功、备用成功、双源失败、未收录、慢响应及并发查词；旧请求不能覆盖新词，失败保留离线结果。只向接口发送所查词语，链接、例句与录音按真实返回显示。
9. 系统语音、在线词典录音与原卷听力互斥；发音失败给反馈。模拟网络只证明处理逻辑，真实联网连通性单独记录，不能计入离线保证。
10. 主课件服务教师：课堂追问默认折叠，语法输入用于可选记录学生答案，写作编辑区是示范板书；不默认生成学生学案。
11. 倒计时、积分、抽号、待复讲回跳、记录导出/导入、字号、全屏和打印可用；移动完整文件夹后实际检查离线使用与媒体解码。
12. 安装包、README、SKILL与实际模板一致。每张新卷分别记录结构、来源内容、原音对应、浏览器行为；没有执行的检查不要写成通过。

## 备课修订、语境收藏与文字标注（2026-09-08）

- 课堂默认只读；“备课编辑”才显示词句修改、隐藏、恢复与补充操作。仍使用生词速查、重点词汇、句子精讲三个入口，不另设长难句或词汇表栏目。教师新增条目必须关联原段落，原句逐字校验；修订用标签区分，原始条目可恢复。隐藏表示本班暂不讲，不能破坏原始试卷。
- 解析可修订答案依据说明、题型说明、解题步骤、方法、易错点及多处证据。标准答案保持原样。修改后的引句必须来自对应段落；改变听力证据文字时，不沿用失去依据的音频时间。
- 收藏词句同时保留段落、原句、语境义和教师备注，同词不同段落不按词面合并。通用释义需标明待结合语境核对。可导出本节已显示词句为CSV；原有课堂收藏保留。
- 原文划选后共用一个查词／收入词句／文字批注浮层；支持高亮、下划线、波浪线、四色、原文备注与移除。文字标记使用原始段落字符范围并核对原句，字号和单双栏变化不能让标记漂移。与Canvas自由板书并存，不增加独立“我的笔记”页面；精听未揭示空位禁止通过划选收藏泄漏。
- 逐题看可以就地选择“本题下方显示相关原文”，使用原来的原文DOM与译文状态；依照本题所有证据段落展示，多处依据不硬裁成一段。保留“回看全文”，没有证据段落时保留全文并说明。离开题目讲评或切回全部题目，恢复正常原文布局。
- 教师修订、隐藏状态、语境收藏和文字批注随既有课堂记录保存、导出与导入。旧记录仍可导入，缺少新字段时清除当前新字段，不能混入另一份记录。导入校验字段、引文及范围，不接受不属于本卷的内容位置。
- 核心功能离线，无需新增API设置。补充条目提供编辑表单，不把未执行的AI重新分析说成自动完成。

## 听力接入三档回归（1.3.0）

老师在别的环境里遇到两个典型故障：听力没出现在课件里、以及流程跑了很久没有结果。以下三条必须逐一实测，不能只看构建是否通过。

1. **完整分段档**：`--audio-bundle` 接入后，页面上每个 Text 有分段播放器、每题有小播放器，`full.mp3` 在完整录音窗口可播；跳转到目标秒数、复听次数、切段停播都实测。
2. **静音自动分段档**：`cut --allow-unverified` 生成的成品仍然能播，页面出现“边界待核对”，build-report.json 的 pending_items 与 quality_gate.warnings 有 `audio_alignment_auto_silence`；qa-report.md 逐段写试听结论。
3. **整卷原音档**：没有 ffmpeg 或没有转写时，只给 `full_audio` 也能构建；页面标签是“整卷原音（未分段）”，报告里有 `audio_unsegmented` 警告，说明逐题复听需人工拖动。
4. **未提供音频档**：用 `audio_note` 写明缺项，页面显示该说明，不出现 src 为空或指向 undefined 的播放器；没有说明时构建必须报错而不是静默少一个章节。
5. **答案链**：故意把一道官方答案改成错误字母，构建必须以 `answer_key_mismatch` 阻断；只改证据句而不改答案时，answer-audit.json 应出现 `evidence_option_low_overlap` 等待核项。

2026-09-05 Z20整卷作为实测例：10页扫描卷、65道编号题+2项写作、102个文本块、10段Text音频及20段单题音频、35项词语精讲、11项句子精讲。最终数据由当前产物验收记录确认。合成演示不可代替这一真卷验证。

## v6：必须一起验证的追加需求

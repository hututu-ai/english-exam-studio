# 依赖下载失败时，避免整次生成卡住

适用：Windows 上 winget/FFmpeg 下载失败、GitHub Release 502、代理超时、模型下载长期不结束。502 只能说明本次网关请求失败，不能由此断言整个 GitHub 不通、另一个下载域名可用或用户代理配置有错。

## 先复用，再安装

- 范围里没有听力：完全跳过 FFmpeg 和 ASR 安装，直接处理选中的文字板块。
- 有听力：运行 doctor，确认两个可执行文件能在 Agent 当前环境运行。优先已有工具、宿主提供的工具目录或用户已解压的便携版。支持 `FFMPEG_BIN`、`FFPROBE_BIN` 指定绝对路径，或 `ENGLISH_EXAM_TOOLS` 指向同时含两者的 bin 目录；仅为当前进程设置，无需修改系统 PATH 或重启电脑。
- Windows 的便携二进制可从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html) 所列的 [Gyan Windows 构建](https://www.gyan.dev/ffmpeg/builds/) 获取。Gyan 是官方链接的第三方构建者，不是 FFmpeg 官方自制安装包。选择适合系统架构的包，按发布者提供的校验值核对。不写死过期版本或使用来路不明镜像。
- 安装需遵循宿主权限；不为了安装改代理、关证书验证、永久改系统 PATH、管理员权限循环重试。用户可直接提供已下载的完整便携包，Agent 校验后在工作目录使用。

## 有上限的安装尝试

安装经授权后，单次依赖准备总预算默认 120 秒（含候选下载源），同时只能有一个下载任务。不要依次跑 winget → curl → 多个镜像，每个都重新给 120 秒。可以使用宿主支持超时和取消的命令工具，或包内脚本：

```text
py -3 scripts/bounded_command.py --seconds 120 -- 已授权的命令 参数
```

该脚本不选下载源、不自动安装，只对明确的命令设置截止时间，关闭标准输入防止等待密码，超时终止本次子进程树。不要把会另行脱离进程树的安装器当作可取消任务。HTTP 502、无法连接或进度停滞时记录完整报错；停止当前失败命令，最多在同一预算内尝试一个已核实的备用地址。保留下载残片便于诊断，但不能把 .part/截断 ZIP 当安装完成。

若宿主没有可追踪的后台进程与回调，不说“下载完成后我会自动收到通知”“等我下一条消息”。在当前任务里读取进度和退出码；老师可以要求取消。超时后明确说明已停止什么，不让老师无期限等待。

## 失败后交付什么

继续完成不依赖该工具的阅读、完形、语法填空与写作。原音若能由浏览器直接播放，则接入完整原音，标注“未分段”；报告列出尚未完成的 Text/逐题切片与精听定位。仅有精听任务时也如实标为部分完成，给出补齐 FFmpeg 后的续跑步骤，不宣称所有功能完成。原音格式浏览器不支持时保留原文件并说明需要转码，不承诺原样复制一定能播。

恢复环境后复用已完成内容，只补切片、音频接线和受影响验证，不重复整卷 OCR/解析。质量报告区分：工具存在、可执行、能编码 MP3、文件可解码、浏览器实际播放、题目边界准确。

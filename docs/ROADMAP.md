# 改进路线图与当前状态

这份文件记录英语实战讲评 Skill 的整体规划、已完成项和仍待真实环境验证的项。判断"是否完成"以这里的标准为准，不用感觉代替证据。

## 当初要解决的六个问题

1. Windows 上必须能跑通（开发只在 macOS 上做过）。
2. 生成太慢。
3. 费 token、费积分。
4. 在豆包工作 / WorkBuddy 下表现要好。
5. 每次生成前让老师自己选需要哪些功能（多选）。
6. 有的老师只要听力，不要整卷。

以及一条贯穿性的要求：**文化背景、篇章结构、重点生词难词、听力挖空都不许 AI 乱编**。

## 判定纪律

- 结构校验通过 ≠ 内容为真：引文锚定只证明"有依据"，词义与背景仍要人工复核。
- CI 绿 ≠ 整卷验收：绿色只代表标准库测试通过，不含浏览器操作与真实材料。
- 没有实机记录的能力，一律写成"未测"，不写成"支持"。

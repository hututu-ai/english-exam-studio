# 老师一页说明：怎么用、遇到问题发什么回来

> 这份是给**老师**看的（不是给助手看的）。助手读 [SKILL.md](../SKILL.md)。

## 这是什么

把**试卷 + 参考答案 + 听力音频**交给助手，它会生成一套**能直接上课的离线 HTML 课件**：
双击 `index.html` 就能讲，不需要联网、不需要登录。你可以自己改内容，也可以只做一部分（比如只要听力）。

## 一、安装（四条路，按可靠性排序）

| 顺序 | 怎么做 | 什么时候用 |
| --- | --- | --- |
| 1 | 把发布 **ZIP 当附件上传**，让助手解压安装 | 最稳，不受平台网络限制（ZIP 约 2MB，微信/邮件都能转发） |
| 2 | 让助手用 `fetch_package.py` 从 `raw.githubusercontent.com` 抓文件 | 平台能开网页但不能 git |
| 3 | 让助手改走 jsDelivr 的 CDN 链接抓同样的文件 | 第 2 条打不开时（第三方 CDN，通常更好打开） |
| 4 | 让助手 `git clone` 仓库 | 前三条都不行时 |

**判断标准只有一条**：助手跑完 `check_install.py` 显示 `complete` 才算装上。没到这一步，就不要相信"已经安装好了"。

**打不开 GitHub、没有梯子**：通常仍然能装——**下载可以发生在别的地方**（手机流量、别的网络、同事的电脑），把 ZIP 传到这台电脑当附件上传即可。第 3 条走的是第三方 CDN：它能保证"传输没损坏"（哈希一致），但**来源是否可信要靠官方 Release 的校验清单**。三条路怎么选、以及助手说"沙盒限制/网络受限"是什么意思，见 [常见问题](FAQ.md) 里的「GitHub 打不开、又没有梯子，还能装吗？」与「助手说"沙盒限制/网络受限"，这是什么意思？」。

## 二、开工前，助手会问你两件事

1. **这次做哪些内容？** A 只做听力 ／ B 整卷讲评 ／ C 指定板块（比如"短文填空"）
2. **需要哪些功能？** 回复编号即可，例如 `1、3、5`

```
1 批注（原文划线、记号、文字批注）   2 查词（点词/划词查询）   3 速对答案
4 课堂工具（计时、计分、随机抽号、打印）   5 篇章精读（结构、逻辑、追问）
6 写作迁移（原句表达、句式、示范改写）   7 文化背景（有来源的背景解读）
```

- **只要听力**：第 1 问答 `A` 就行——**不需要另装一个"听力版"**，同一套 Skill。
- 没选的扩展**不会生成、也不会显示入口**，所以只挑这次真正要讲的，生成更快、额度更省。
- 不想每次选：告诉助手"沿用上次"。

## 三、要交给助手的材料

- 试卷：PDF／图片／DOCX 都行，**只有手机拍的图片也可以**（一张照片两页也没关系，告诉助手即可）；
- 答案：官方答案原件最好；只有图片答案也能用（助手会标成"读图转录"，并要求逐题与答案原图核对）；
- 听力：音频文件；有同源字幕/转写更好（可以跳过转写）。
- 材料越齐、越少来回补，生成越快。

## 四、你会拿到什么

一个 ZIP，解压后：

```
index.html        课件本体（双击打开）
打开课件.html      打不开时的说明页
exam.json         内容数据（要改内容就改它，再让助手重建）
audio/            听力音频（完整/分段/逐题）
sources/          原卷页图（提供过的话）
build-report.json 构建与检查报告
answer-audit.json 逐题答案核对结果
qa-report.md      交付前人工复核记录
```

## 五、上课前花两分钟抽查

- 抽 2–3 道题：答案与解析的依据句是否对得上原卷；
- 有听力：听一下每段的首尾是否切在题目之间；
- 点一下"答案与解析""速对答案""批注"，确认能用。

## 六、遇到问题，发什么回来最有用

**首选**：在那台电脑上跑一次

```bat
py -3 scripts\smoke_report.py --zip
```

把生成的 `smoke-report-windows.zip` 发回。它只含报告文本（不含试卷和音频），对方一条命令就能判读"能证明什么、还不能证明什么"。

**不想敲命令**：在解压出来的文件夹里**双击 `一键体检.bat`**（和 `SKILL.md` 同一层）就行——它会跑完上面这条命令、把报告 zip 生成在当前目录，并停住让你看路径。

**或者**在对话里说清三件事：

1. **哪一步**出问题（安装／识别材料／生成／打开课件／上课操作）；
2. **原话报错**（截图或复制文字，不要转述）；
3. **哪份文件**（文件名即可；课件问题请说明是哪一节、哪一题）。

## 七、请避免

- **不要手工改 `index.html`**：模板指纹会失效，交付闸门会拒绝打包，也容易改坏；要改内容改 `exam.json`；确实要改界面，让助手改模板并重新验收。
- 不要把真实试卷、答案或教辅转发给无关的人。
- 助手如果说"已完成"，你可以追问一句：**浏览器点击验收做了吗？qa-report 写了吗？**——这两项齐全才算交付完成。

# 第一次安装与环境准备

**老师可以先把下面这段话交给 AI 助手，让它检查并准备环境。** 不需要先学习命令行，再自己切听力。

```text
我要使用英语实战讲评 Skill（english-exam-studio）。项目地址：
https://github.com/hututu-ai/english-exam-studio

请先阅读项目 README 和 SKILL.md，按你当前平台支持的方式安装或确认技能已启用，并检查：
1. 你是否能读取我的试卷、答案和音频，识别 PDF/扫描页，执行本地脚本并写出课件文件。
2. Python 3 是否可用；本项目自带 Python 脚本使用标准库，不要仅因为是 Python 项目就安装一批无关软件包。
3. 有听力时，ffmpeg 和 ffprobe 是否能在你实际执行任务的环境中运行，且能够导出 MP3。
4. 如果需要本地转写，检查 whisper.cpp 的 whisper-cli 和兼容模型文件；如果已有可靠的带时间转写，可以复用并转换成项目需要的格式。

优先复用已经可用的工具。缺少时按我的系统和当前平台权限准备；遇到确需我处理的安装或授权，请说明具体操作。不要猜模型路径，也不要把其他名称相似的 Whisper 包当成已经满足要求。

最后用一个小样例验证能否生成并打开 HTML；有听力时再验证音频识别、裁剪和播放。请告诉我哪些环节已验证、哪些还需要准备，然后继续接收我的材料。
```

## 1. 安装在哪里？

这套 Skill 要安装到**能使用模型、处理文件并执行脚本的 AI 助手**中。HTML 是最后生成的课件，不承担安装 Skill 或自动备课的工作。

检查宿主工具是否具备：

- 能安装或读取自定义 `SKILL.md`，保留配套 `scripts/`、`assets/`、`references/`。
- 能读取老师提供的材料；扫描卷还需要图像识别或 OCR 能力。
- 能运行 Python 和需要的音频工具，保存完整文件夹，而非只返回一段文字。
- 能使用模型整理内容、核对题目、编写讲评，并检查生成结果。

只有普通聊天功能、不能执行文件任务的平台，可能能帮你写解析，但不能据此承诺跑通这套完整流程。

### 以 WorkBuddy 的导入入口为例

按照官方说明，在“技能”中选择“添加技能 → 上传技能”，选择本地技能包；界面确认导入后，在“已安装”中确认启用。[WorkBuddy 官方技能说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)

**本项目尚未完成 WorkBuddy 上的整套实机验收。** 官方支持本地包导入，和本包已经在该平台完成材料识别、音频处理、课件生成，是两个不同层次。首次使用请让助手执行上面的检查，并以实际版本的导入结果为准。

下载时优先使用项目发布页提供的 Skill 包。GitHub 的“Code → Download ZIP”下载的是整个源码仓库；若平台无法识别其外层目录，让助手确认 `SKILL.md` 所在文件夹并按平台规则整理，保持模板和脚本完整，不只复制一个 Markdown 文件。

## 2. 哪些东西真的需要安装？

| 环节 | 所需能力 | 是否每位老师都要手动装 |
|---|---|---|
| 生成内容和判断题意 | 宿主 AI 的模型与文件处理能力 | 使用已经可用的 AI 助手；不用给课件另配模型 API |
| 构建 HTML、提取 DOCX、本地预览 | Python 3；自带脚本使用标准库 | 优先复用助手自带环境；建议使用 Python 3.11 或更新的稳定版本 |
| 扫描 PDF、试卷照片 | 宿主的视觉识别或 OCR 工具 | 由助手按材料情况选择；`extract.py` 本身只负责 DOCX，不是完整 PDF OCR 引擎 |
| 检查时长、转换和裁剪音频 | `ffmpeg`、`ffprobe`，导出时需支持 MP3 编码 | 有听力任务时需要；交给助手检查并准备 |
| 从原音产生带时间的转写 | `whisper.cpp` 的 `whisper-cli`＋兼容本地模型，或可复用的可靠时间转写 | 两种路线择一，不要求所有机器采用同一个模型 |
| 打开已生成课件上课 | 现代浏览器＋完整课件文件夹 | 教室电脑只播放成品时，不需安装 Python、FFmpeg 或 Skill |

Python、FFmpeg、转写模型是不同的东西。安装 Python 不会自动安装 FFmpeg；运行 `pip install whisper` 或安装其他 Whisper 包，也不等于获得了本项目调用的 `whisper-cli`。

## 3. 听力转写的两条路线

### 路线 A：本地 whisper.cpp

助手需要确认 `whisper-cli` 可调用，并找到与其兼容、实际存在的模型文件。模型路径通过 `--model` 或 `WHISPER_MODEL` 提供，不能照抄别人的电脑路径。程序和模型通常需要分别准备；模型的速度与准确性取决于机器和录音，专名、否定、重复朗读等仍要核对。[whisper.cpp 官方说明](https://github.com/ggml-org/whisper.cpp)

### 路线 B：复用可靠的带时间转写

如果助手已有其他可靠的转写结果，可以转换为以下格式，通过 `--transcript` 复用：

```json
{
  "segments": [
    {"start": 0.5, "end": 2.8, "text": "Good morning."},
    {"start": 3.1, "end": 5.4, "text": "Are you ready to leave?"}
  ]
}
```

时间单位是秒，参照**完整原始音频**。以上只是格式示例，不能直接当作你的录音时间。普通 Word 听力原文只有文字，没有时间信息，不能直接代替这份转写。

两条路线都还需要依据题意确认 Text 和逐题录音的边界。文字转写、静音和题号提示用于辅助判断，不能把音频机械均分，也不能仅按字数猜时间。

## 4. 不同电脑怎么准备？

老师可以跳过这一节，由助手处理。以下给需要协助排查的同事或技术支持人员使用。

| 系统 | 需要注意的地方 |
|---|---|
| macOS | 先检查助手是否已有 Python 和音频工具。通过现有包管理器或官方推荐方式安装时，Intel 和 Apple Silicon 的安装位置可能不同；不要写死 Homebrew 或模型目录。 |
| Windows | Python 入口可能是 `py -3` 或 `python`。FFmpeg 解压后需让 `ffmpeg.exe`、`ffprobe.exe` 在助手的执行环境可找到；转写程序可能名为 `whisper-cli.exe`。仅在另一个终端能运行，不代表助手进程已经取得同样的 PATH。 |
| Linux | 可使用发行版的 Python 和 FFmpeg 包；whisper.cpp 按官方方式获取或构建。容器或远程执行环境要实际能访问材料目录，不能只传一个本机路径。 |

FFmpeg 官方下载页提供源码及不同系统的构建入口；按当前系统选取，不要从无关软件下载站盲装。[FFmpeg 官方下载](https://ffmpeg.org/download.html)

安装后应在**助手实际执行任务的环境**中确认这些入口：

```text
Python 3 可以执行
ffmpeg -version
ffprobe -version
whisper-cli -h（仅本地转写路线需要）
模型文件存在且可以加载（仅本地转写路线需要）
```

如果涉及需要系统权限的安装，助手应具体说明原因和范围；老师可以让学校技术人员帮助准备一次，以后复用。各系统的依赖可安装，不表示本项目已完成每种系统、每个宿主版本的验收。

## 5. 第一次生成之前准备什么？

将同一次考试的材料一起提供给助手：试卷、参考答案、听力音频，以及已有的听力原文。扫描件不要漏页，照片保留完整题干与选项。不同版本试卷请明确标注，避免把 A 卷和 B 卷答案混用。

然后告诉助手：

```text
请使用英语实战讲评 Skill（english-exam-studio），根据这些材料制作完整教师课件。
保留全部已提供题型、原文和逐题讲评；听力提供整段与逐题录音；检查题号、答案、证据和音频对应关系。
完成后给我可直接打开的成品、完整文件夹和压缩包，并说明仍需核对的具体项目。
```

生成完毕后，先打开 `index.html`，试用本节要讲的题目和音频。若浏览器文件模式下不能可靠跳到指定秒数，可让助手运行项目自带的本地预览服务。下面的路径需要替换为真实课件目录，命令从 Skill 根目录执行：

```bash
python3 scripts/preview.py "你的课件文件夹" --port 8918
```

打开服务实际返回的本机地址。服务提供音频分段读取支持，方便验证定位复听；它不是上传公网，不会让其他老师通过你的 `127.0.0.1` 地址访问课件。端口占用时换一个端口，Windows 可按实际 Python 入口调整命令。
